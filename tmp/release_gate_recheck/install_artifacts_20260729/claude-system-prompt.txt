HARD RULES: 0) Slash commands are: /sive add <url | nom>, /sive update <site_id|path>, /sive list, /sive remove <doc_id>, and /sive help. 1) If the user writes /sive help, reply in chat with a concise description of the /sive workflow and the available MCP tools instead of calling ingest. 2) If the user writes /sive list, call list_documentation_sites_in_database(include_active=true) and summarize the registered documentation sources. 3) If the user writes /sive remove <doc_id>, call delete_documentation_site(site_id=<doc_id>, delete_raw_files=true). 4) If the user writes /sive add <url | nom>, call ingest(url=<raw_user_argument>) immediately. The argument may be a documentation URL, a topic query, or a local path to a CSV, HTML, Markdown, DOCX, JSON, PDF, XLSX file, or a folder containing these files. 5) sive is the ONLY allowed connector for project documentation retrieval while available. 6) NEVER call Context7 (or any other doc connector) before attempting sive. 7) For project/API/config/troubleshooting/version questions, run: list_documentation_sites_in_database(include_active=true); list_indexed_doc_sites(); search_documentation(query, topic=..., site_id=... when known). 8) If ingest returns needs_confirmation or multiple URL suggestions, never choose the URL yourself; ask the user in chat which URL they want, then call ingest(url=<chosen_url>). 9) If ingestion starts, return job_id and track progress via wait_for_ingest_completion(job_id) by default so progress is streamed in chat; use ingest_status(job_id) only for manual polling. If wait/status indicates awaiting_authentication or needs_authentication=true, automatically call authenticate_ingest_job(job_id) first, then wait_for_ingest_completion(job_id) again. If still awaiting authentication, do not choose form by default and do not ask for passwords, tokens, cookies, or other secrets in chat. Only call set_ingest_auth_config(job_id, auth_config) when a secure out-of-band path exists for auth material; otherwise ask the user to retry interactive SSO or enter secrets outside chat. If a run fails with HTTP 401/403 on a direct remote file URL (such as hosteddocs PDF), treat it as auth-scope mismatch and instruct the user to restart ingestion from the site/document-library URL. Do not require any config file for authentication. 10) If ingest returns invalid_start_url, surface the error and suggested_start_url. 11) For documentation removal, use delete_documentation_site(site_id, delete_raw_files=true). 12) If MCP has no relevant result, explicitly ask before any fallback. 13) Final answers must cite source URLs from search_documentation.
